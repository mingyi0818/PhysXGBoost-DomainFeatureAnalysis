## 2. 当前研究痛点

### 2.1 方法层面

1. **时域特征单一性**：现有电力窃电检测方法几乎全部依赖时域特征（CNN/RNN/LSTM/Transformer处理原始时序），**完全忽略了频域信息**。电力消费数据具有明显的周期性（日周期、周周期、季节周期），这些周期性在频域中更容易被捕获。FCVAE (WWW 2024) 和 TriAD 2 (ICDE 2024) 已在通用时序异常检测中证明频域信息的重要性，但**尚未被应用于电力窃电检测**。

2. **无监督学习范式不足**：大多数现有方法采用纯监督学习，需要大量标注数据。在实际部署中，窃电标签获取成本极高且存在标签噪声。对比学习作为一种强大的自监督/半监督方法，在计算机视觉和NLP领域已取得巨大成功，但在**电力异常检测中的应用极少**。

3. **重构方法的局限性**：基于自编码器/VAE的重构方法存在"过度重构"问题——模型可能对异常样本也能较好地重构，导致异常检测失败。现有解决方案（如记忆增强AE、对抗训练）增加了模型复杂度且训练不稳定。

4. **特征融合缺乏自适应性**：少数尝试多视角特征的方法（如双时域特征融合 [Huang et al., 2024]）使用简单的拼接或固定权重融合，**无法自适应地学习不同特征的重要性**。

### 2.2 实验层面

5. **评估指标不完整**：SGCC数据集上的多数论文仅报告Accuracy，**不报告AUC-ROC、F1-Score、Precision、Recall**等关键指标。在异常比例~9%的不平衡数据上，Accuracy具有严重误导性（全预测为正常可达91%准确率）。

6. **缺乏统计显著性检验**：现有工作大多使用单次实验结果，不报告多种子实验的均值±标准差，不进行统计显著性检验。

7. **消融实验不充分**：多数论文不进行组件级消融实验，无法验证各模块的贡献。

8. **缺乏参数敏感性分析**：不分析关键超参数（如学习率、对比损失温度、重构/对比损失权重比）对性能的影响。

### 2.3 理论层面

9. **理论分析严重缺失**：现有电力窃电检测论文几乎没有理论贡献——没有收敛性分析、没有泛化界、没有复杂度分析、没有概率论基础。

10. **对比学习理论基础未建立**：在电力异常检测场景下，对比学习的正负样本构造、损失函数设计缺乏信息论和概率论的理论支撑。

## 5. 击破方案

### 5.1 核心创新点

**创新点1：时域-频域双编码器架构**
- 时域编码器：多尺度1D-CNN (kernel sizes: 3, 5, 7) + 残差连接 + 多头自注意力
- 频域编码器：FFT提取频谱幅度 + L2归一化 + MLP编码
- 自适应门控融合：`gate = Softmax(Linear([time_emb, freq_emb]))`，学习时域/频域特征的最优权重组合
- **击破点**：现有电力窃电检测方法全部仅用时域特征，TCR-AD首次引入频域编码器并自适应融合

**创新点2：对比学习-重构联合优化框架**
- 对比损失(NT-Xent)：约束正常样本的嵌入空间，使相似正常模式聚集
- 重构损失(MSE)：确保嵌入保留足够的时序信息以重构原始输入
- 分类损失(BCE)：利用少量标签信息指导特征学习
- 联合损失：`L = α·L_contrastive + β·L_reconstruction + γ·L_classification`
- **击破点**：对比学习防止重构模型对异常样本的过度适配，重构约束防止对比学习坍缩到平凡解

**创新点3：正常样本建模的异常评分机制**
- 训练阶段：对比学习和重构仅使用正常样本(y=0)，分类头使用全部样本
- 推理阶段：异常评分 = 重构误差（正常样本重构误差低，异常样本重构误差高）
- **击破点**：符合异常检测的核心假设——只学习正常模式，通过偏离程度检测异常

### 5.2 理论贡献

**定理1（收敛性）**：在适当学习率条件下，TCR-AD的联合损失函数L(θ)在训练过程中单调递减，且收敛到局部最小值。

**定理2（泛化界）**：基于Rademacher复杂度，TCR-AD的泛化误差上界为：
`R(h) ≤ R_emp(h) + O(sqrt(d/n)) + O(sqrt(log(1/δ)/n))`
其中d为模型复杂度，n为样本数。

**命题1（对比学习的异常检测概率解释）**：NT-Xent损失等价于最大化正常样本的互信息下界，互信息越大，异常样本与正常样本的区分度越高。

**复杂度分析**：
- 时间复杂度：O(n·L·k·d²) 其中n=样本数, L=序列长度, k=卷积核数, d=嵌入维度
- 空间复杂度：O(n·d + d²)

## 6. 理论分析框架

### 6.1 问题形式化

给定正常用电序列集合 $\mathcal{D}_n = \{x_1, ..., x_N\}$ 和带标签集合 $\mathcal{D}_l = \{(x_i, y_i)\}_{i=1}^M$，其中 $y_i \in \{0, 1\}$，目标是学习函数 $f: \mathcal{X} \to \mathbb{R}$ 使得 $f(x) > \tau$ 时判定为异常。

### 6.2 时域编码器

多尺度卷积：
$$h_t^{(k)} = \text{Conv1D}_k(x; W_k), \quad k \in \{3, 5, 7\}$$

融合：
$$h_t = \text{Conv1D}_1(\text{Concat}(h_t^{(3)}, h_t^{(5)}, h_t^{(7)}))$$

自注意力：
$$\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

### 6.3 频域编码器

FFT变换：
$$X_f = \text{FFT}(x), \quad |X_f| = \sqrt{\text{Re}(X_f)^2 + \text{Im}(X_f)^2}$$

归一化与编码：
$$h_f = \text{MLP}\left(\frac{|X_f|}{\|X_f\|_2}\right)$$

### 6.4 门控融合

$$g = \text{Softmax}(W_g[h_t; h_f])$$
$$h = g_1 \cdot h_t + g_2 \cdot h_f$$

### 6.5 损失函数

NT-Xent对比损失：
$$\mathcal{L}_{\text{con}} = -\frac{1}{N}\sum_{i=1}^{N} \log \frac{\exp(\text{sim}(z_i, z_i^+)/\tau)}{\sum_{j=0}^{2N-1} \mathbb{1}_{j \neq i} \exp(\text{sim}(z_i, z_j)/\tau)}$$

重构损失：
$$\mathcal{L}_{\text{rec}} = \frac{1}{N}\sum_{i=1}^{N} \|x_i - \hat{x}_i\|_2^2$$

分类损失：
$$\mathcal{L}_{\text{cls}} = -\frac{1}{N}\sum_{i=1}^{N} [y_i \log \sigma(h_i) + (1-y_i) \log(1-\sigma(h_i))]$$

联合损失：
$$\mathcal{L} = \alpha \mathcal{L}_{\text{con}} + \beta \mathcal{L}_{\text{rec}} + \gamma \mathcal{L}_{\text{cls}}$$

## 10. 风险提示

1. **实验结果风险**：TCR-AD可能在SGCC数据集上不如某些深度学习基线（如Wide and Deep CNN），因为SGCC的时序模式可能更适合时域特征。**应对方案**：频域编码器作为补充而非替代，门控融合可自适应降低频域权重。

2. **训练稳定性风险**：对比学习+重构联合优化可能出现损失震荡。**应对方案**：使用余弦退火学习率调度 + 梯度裁剪 + 早停。

3. **数据不平衡风险**：9%异常比例可能导致模型偏向多数类。**应对方案**：分类头使用加权BCE损失；评估指标以AUC-ROC和F1为主。

4. **内存风险**：SGCC数据42K×1035，30%采样后约12K×1035。SUB_SEQ_LEN=256的子序列训练，batch_size=256，在16GB显存下应可运行。**应对方案**：如OOM则降低batch_size或sample_ratio。

5. **理论推导风险**：泛化界推导可能不够严格。**应对方案**：引用标准Rademacher复杂度文献，确保推导过程可验证。
