# 49_Superconductor SOTA击破分析

> 方向：材料科学领域特征增强的超导临界温度预测
> 撰写日期：2026-08-10

## 1. 基本信息

| 项目 | 内容 |
|------|------|
| 方法 | MatFeat: Material Science Domain Feature Analysis for Superconductor Critical Temperature Prediction |
| 数据集 | UCI Superconductivity (21,263 samples, 81 features, regression) |
| 已有结果 | Raw R²: 0.894-0.925, Domain R²: 0.895-0.925 (几乎无差异) |

## 2. SOTA共同缺点

| 缺点 | 解决方案 |
|------|---------|
| 无特征物理可解释性 | SHAP+材料物理性质关联分析 |
| 无特征冗余分析 | 互信息特征聚类+冗余度量化 |
| 无统计检验 | 5种子+Wilcoxon+95%CI |
| 无特征信息饱和分析 | 信息论框架解释为何领域特征无效 |

## 3. 击破方案

**创新点1**：材料科学领域特征工程框架
- 元素属性衍生(element_*)：原子半径/电负性/原子量的统计量
- 结构特征(struct_*)：晶体结构编码/配位数
- 热力学特征(thermo_*)：德拜温度/费米能级估计
- 电子特征(elec_*)：电子密度/价电子数交互

**创新点2**：特征信息饱和性分析
- 原始81个特征已包含丰富的化学/物理信息
- 推导：当原始特征信息量接近饱和时，领域特征增益趋近于零

**定理1**（信息饱和性）：对于回归任务，当R²(F)≥1-ε，新增特征D的R²增量≤O(ε)。

**命题1**（特征冗余判据）：若领域特征D与原始特征集F的互信息I(D;F) > I(D;Y|F)，则D对回归的边际贡献为负。

**创新点3**：SHAP物理可解释性
- 将SHAP特征重要性与材料物理性质关联
- 验证模型学到的特征重要性是否符合材料科学直觉
- 特征聚类分析揭示化学元素分组

## 4. 实验设计
| 实验 | 内容 |
|------|------|
| 主对比 | 4模型×2特征集(Raw/Domain) |
| SHAP物理可解释性 | 特征重要性+材料物理关联 |
| 特征聚类 | 基于互信息的层次聚类 |
| 消融 | 4类领域特征逐一移除 |
| 统计 | 5种子+Wilcoxon+95%CI |
| 参数敏感性 | 学习率/树深度/估计器数量 |
