# 49_Superconductor 参考文献调研材料

> 调研日期：2026-08-10
> 数据集：UCI Superconductivity (21,263 samples, 81 features, regression task)

## 研究现状
超导临界温度预测是材料科学中的重要回归问题。2024-2026年趋势：
- 图神经网络（GNN）用于材料属性预测
- 主动学习用于材料发现
- Transformer用于材料序列建模
- 树模型仍是强基线

## 本方向已有结果
| 模型 | Raw R² | Domain R² |
|------|---------|-----------|
| XGBoost | 0.9245 | 0.9246 |
| LightGBM | 0.9179 | 0.9181 |
| CatBoost | 0.8943 | 0.8947 |
| RandomForest | 0.9225 | 0.9225 |

**关键发现**：Domain特征对超导预测几乎无影响（±0.0004），因为原始81个特征已包含丰富的化学/物理信息。

## 击破方案
- 创新点：材料科学领域特征分析框架 + 特征重要性物理可解释性
- 核心贡献：将SHAP特征重要性与材料物理性质关联，提供可解释性
- 理论：特征信息量分析 — 当原始特征集信息量接近饱和时，领域特征增益趋近于零
- 实验：4模型对比 + SHAP物理可解释性 + 特征聚类分析 + 消融
- 目标期刊：IJMLC (EI) 或 IEEE Access (SCI四区)
