# Highlights

- Building physics domain features improve appliance energy prediction R² by 2.2--4.2 percentage points
- Temperature-Humidity Index and indoor-outdoor temperature differential are the most impactful derived features
- Fair comparison of XGBoost, LightGBM, CatBoost, and Random Forest with 7-seed statistical testing
- 19,735 ten-minute measurements from a nine-room residential sensor network
- Physics-derived features enable interpretable energy prediction without black-box deep learning
