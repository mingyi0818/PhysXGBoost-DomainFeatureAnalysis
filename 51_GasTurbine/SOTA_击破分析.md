## 3. 击破方案

**创新点1**：热力学领域特征工程框架
- thermodynamic_* (效率比, 热耗率): 基于Brayton循环的热效率估计
- combustion_* (空气-燃料交互): 当量比估计, 燃烧温度比
- load_* (运行工况): 负载分段编码, 变工况斜率
- ambient_* (环境修正): 海拔修正系数, 湿度修正因子

**创新点2**：特征信息饱和性分析
- 原始11个特征已包含丰富的热力学信息
- 推导：当原始特征信息量接近饱和时，领域特征增益趋近于零

**定理1**（特征交互界）：对于回归任务，给定特征集F和新特征D，条件互信息 I(Y;D|F) 的上界由 F 对 Y 的解释力度决定：I(Y;D|F) <= H(Y) - H(Y|F) = I(Y;F)。当 I(Y;F) 接近 H(Y) 时，D 的边际信息增益趋近于零。

**命题1**（特征冗余判据）：若领域特征 D 与原始特征集 F 的互信息 I(D;F) > I(D;Y|F)，则 D 对回归的边际贡献为负（引入噪声而非信号）。

**创新点3**：SHAP热力学可解释性
- 将SHAP特征重要性与热力学物理性质关联
- 验证模型学到的特征重要性是否符合热力学直觉
- 特征聚类分析揭示热力学生成机理

## 4. 实验设计

| 实验 | 内容 |
|------|------|
| 主对比 | 4模型 x 2特征集(Raw/Domain) |
| SHAP热力学可解释性 | 特征重要性 + 热力学物理关联 |
| 特征聚类 | 基于互信息的层次聚类 |
| 消融 | 4类领域特征逐一移除(thermodynamic/combustion/load/ambient) |
| 统计 | 5种子 + Wilcoxon + 95% CI + Cohen's d |
| 参数敏感性 | 学习率/树深度/估计器数量, 弹性系数等级 |
| 复杂度分析 | 理论O(N*d) + 实际运行时间/内存/FLOPs |

- 领域特征几乎无效果(最大+0.0015)，核心贡献转向可解释性和理论分析
