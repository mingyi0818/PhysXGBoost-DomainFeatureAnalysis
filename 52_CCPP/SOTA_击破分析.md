## 2. SOTA共同缺点

| 缺点 | 解决方案 |
|------|---------|
| 无热力学理论分析 | 基于Carnot循环的特征信息饱和性证明 |

## 3. 击破方案

**创新点1**：热力学领域特征工程框架
- thermo_* (焓估计, Carnot效率): 基于AT和AP的Carnot效率上限, 理论最大功
- humidity_* (湿球温度, 露点): Stull湿球温度公式, 露点温度估计
- interaction_* (AT x V, AP x RH): 热力学交互项, 温度-真空度耦合

**创新点2**：特征信息饱和性分析
- 仅4个原始特征已达R2 > 0.96，信息量接近饱和
- 推导：当原始特征集已捕获96%+方差时，领域特征增益上限极小

**定理1**（特征交互界）：对于回归任务 Y = f(X) + epsilon，给定特征集 F 和新特征 D，条件互信息满足 I(Y;D|F) <= H(Y|F) - H(Y|F,D)。当 R2(F) >= 1 - epsilon 时，H(Y|F) = O(epsilon)，故 I(Y;D|F) = O(epsilon)，即新特征的信息增益被原始特征的解释力度上界约束。

**命题1**（特征冗余判据）：若领域特征 D 与原始特征集 F 的互信息 I(D;F) > I(D;Y|F)，则 D 对回归的边际贡献为负。在CCPP数据集中，thermo_*特征与AT/V高度相关，故I(D;F)大而I(D;Y|F)小。

**创新点3**：SHAP热力学可解释性
- SHAP特征重要性 + Carnot循环物理直觉验证
- 验证AT是最重要特征是否符合热力学第二定律
- 湿度衍生特征的边际贡献分析

## 4. 实验设计

| 实验 | 内容 |
|------|------|
| 主对比 | 4模型 x 2特征集(Raw/Domain) |
| SHAP热力学可解释性 | 特征重要性 + Carnot循环关联 |
| 特征聚类 | 基于互信息的层次聚类 |
| 消融 | 3类领域特征逐一移除(thermo/humidity/interaction) |
| 统计 | 5种子 + Wilcoxon + 95% CI + Cohen's d |
| 参数敏感性 | 学习率/树深度/估计器数量, 弹性系数等级 |
| 复杂度分析 | 理论O(N*d) + 实际运行时间/内存/FLOPs |
