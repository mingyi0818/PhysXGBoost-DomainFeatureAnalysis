## 3. 击破方案

**创新点1**：城市出行领域特征工程框架
- temporal_* (高峰时段, 周末模式): rush_hour标志, weekend vs weekday模式编码
- weather_* (舒适度指数, 天气严重度): 温度-湿度-风速综合舒适度, 天气恶化梯度
- user_* (casual/registered比例): 用户类型行为差异特征
- seasonal_* (旅游季节): 基于月份的旅游高峰编码

**创新点2**：特征信息增益分析
- 原始12特征已达R2 > 0.937，领域特征提供一致但小幅的提升
- 推导：领域特征捕获了原始特征未编码的出行行为模式

**定理1**（特征交互界）：对于回归任务，给定原始特征集F和新特征D，R2增量 Delta(R2) 满足 Delta(R2) <= I(Y;D|F) / H(Y)。当领域特征D包含F未捕获的出行行为信息时，I(Y;D|F) > 0，故Delta(R2) > 0但受限于H(Y) - I(Y;F)。

**命题1**（特征冗余判据）：若领域特征D与原始特征集F的互信息 I(D;F) > I(D;Y|F)，则D的边际贡献为负。temporal_*特征与hr/weekday存在部分冗余，但rush_hour编码了非线性交互，故I(D;Y|F)仍为正。

**创新点3**：SHAP出行行为可解释性
- SHAP特征重要性 + 出行行为理论关联
- 验证高峰时段特征重要性是否符合通勤直觉
- 天气舒适度对casual vs registered用户的差异化影响

## 4. 实验设计

| 实验 | 内容 |
|------|------|
| 主对比 | 4模型 x 2特征集(Raw/Domain) |
| SHAP出行可解释性 | 特征重要性 + 通勤行为关联 |
| 特征聚类 | 基于互信息的层次聚类 |
| 消融 | 4类领域特征逐一移除(temporal/weather/user/seasonal) |
| 统计 | 5种子 + Wilcoxon + 95% CI + Cohen's d |
| 参数敏感性 | 学习率/树深度/估计器数量, 弹性系数等级 |
| 复杂度分析 | 理论O(N*d) + 实际运行时间/内存/FLOPs |
