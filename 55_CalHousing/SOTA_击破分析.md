## 2. SOTA共同缺点

| 缺点 | 解决方案 |
|------|---------|
| 无地理-人口特征理论 | 基于城市经济学的特征交互界分析 |
| 无特征冗余量化 | 互信息 + 条件互信息分析 |
| 无统计检验 | 5种子 + Wilcoxon + 95% CI |
| 无参数敏感性 | 弹性系数量化超参影响 |

## 3. 击破方案

**创新点1**：地理-人口领域特征工程框架
- geo_* (位置聚类, 海岸距离): K-means位置聚类, Haversine距离到太平洋
- demo_* (收入-年龄交互, 房间密度): MedInc x HouseAge, AveRooms / AveBedrms
- econ_* (可负担性指数): MedInc / median_house_value近似
- spatial_* (邻域统计): 局部KNN均值/标准差

**创新点2**：特征信息增益分析
- 原始8特征R2为0.79-0.84，仍有提升空间
- 地理特征捕获了原始经纬度未编码的空间结构信息

**定理1**（特征交互界）：对于回归任务 Y = f(X) + epsilon，给定特征集F和新特征D，R2增量 Delta(R2) 满足 Delta(R2) <= [H(Y) - I(Y;F)] / H(Y) = 1 - R2(F)。当 R2(F) = 0.84 时，理论上界 Delta(R2) <= 0.16，实际增益受D与F的冗余度约束。

**命题1**（特征冗余判据）：若领域特征D与原始特征集F的互信息 I(D;F) > I(D;Y|F)，则D的边际贡献为负。geo_*特征虽与Lat/Long相关，但聚类编码了非线性空间结构，故I(D;Y|F) > 0。

**创新点3**：SHAP地理经济学可解释性
- SHAP特征重要性 + 城市经济学理论关联
- 验证海岸距离特征重要性是否符合房价梯度理论
- 收入-年龄交互对房价的非线性影响分析

## 4. 实验设计

| 实验 | 内容 |
|------|------|
| 主对比 | 4模型 x 2特征集(Raw/Domain) |
| SHAP地理经济学可解释性 | 特征重要性 + 空间经济关联 |
| 特征聚类 | 基于互信息的层次聚类 |
| 消融 | 4类领域特征逐一移除(geo/demo/econ/spatial) |
| 统计 | 5种子 + Wilcoxon + 95% CI + Cohen's d |
| 参数敏感性 | 学习率/树深度/估计器数量, 弹性系数等级 |
| 复杂度分析 | 理论O(N*d) + 实际运行时间/内存/FLOPs |
