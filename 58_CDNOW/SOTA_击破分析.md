## 2. SOTA共同缺点

| 缺点 | 解决方案 |
|------|---------|
| 无客户行为理论分析 | 基于客户关系管理的特征交互界分析 |
| 无特征冗余量化 | 互信息 + 条件互信息分析 |
| 无统计检验 | 5种子 + Wilcoxon + 95% CI |
| 无参数敏感性 | 弹性系数量化超参影响 |
| 无可解释性 | SHAP + 客户行为理论关联 |

## 3. 击破方案

**创新点1**：客户行为领域特征工程框架
- rfm_* (recency, frequency, monetary): 最近购买距今天数, 购买总次数, 总消费金额, 平均消费金额
- temporal_* (购买时序): 购买间隔均值/标准差, 购买间隔趋势, 首次购买距今天数
- loyalty_* (客户任期): 客户活跃天数, 购买频率变化率, 流失风险评分

**创新点2**：特征信息饱和性分析
- 原始RFM特征已包含大部分客户行为信息
- 推导：当原始RFM特征信息量接近饱和时，领域特征增益趋近于零

**定理1**（特征交互界）：对于分类任务 Y in {0,1}，给定特征集F和新特征D，条件互信息 I(Y;D|F) <= H(Y) - I(Y;F)。当 I(Y;F) 接近 H(Y) 时（即AUC接近1.0时），D的边际信息增益趋近于零。在CDNOW数据集中 AUC(F) approx 0.827，剩余信息量有限。

**命题1**（特征冗余判据）：若领域特征D与原始特征集F的互信息 I(D;F) > I(D;Y|F)，则D对分类的边际贡献为负。temporal_*和loyalty_*特征与RFM高度相关，故I(D;F)大而I(D;Y|F)小。

**创新点3**：SHAP客户行为可解释性
- SHAP特征重要性 + 客户生命周期理论关联
- 验证recency/frequency特征重要性是否符合客户关系管理直觉
- 购买间隔趋势对客户流失预测的边际贡献分析

## 4. 实验设计

| 实验 | 内容 |
|------|------|
| 主对比 | 4模型 x 2特征集(Raw/Domain) |
| SHAP客户行为可解释性 | 特征重要性 + CRM理论关联 |
| 特征聚类 | 基于互信息的层次聚类 |
| 消融 | 3类领域特征逐一移除(rfm/temporal/loyalty) |
| 统计 | 5种子 + Wilcoxon + 95% CI + Cohen's d |
| 参数敏感性 | 学习率/树深度/估计器数量, 弹性系数等级 |
| 复杂度分析 | 理论O(N*d) + 实际运行时间/内存/FLOPs |
