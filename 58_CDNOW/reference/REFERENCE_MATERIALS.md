# 58_CDNOW 参考材料

## 1. 数据集描述

| 项目 | 内容 |
|------|------|
| 名称 | CDNOW Dataset |
| 来源 | CDNOW Inc. (通过 UCI/BTS 提供) |
| 样本数 | 6,919 |
| 特征数 | 从交易历史中提取的RFM及时间特征 |
| 任务类型 | 二分类 (预测客户是否重复购买) |
| 文件路径 | data/cdnow.csv |

### 数据说明
- 原始数据为CDNOW公司客户交易记录
- 每条记录包含客户ID、交易日期、购买数量、购买金额
- 从交易历史中提取RFM特征用于客户重复购买预测
- 目标变量: 客户在未来时间窗口内是否再次购买 (0/1)

## 3. 研究空白

1. **RFM特征信息饱和性缺乏理论分析**：传统RFM特征已包含大部分客户行为信息，领域特征增益趋近于零
2. **客户忠诚度特征理论不足**：客户任期、购买频率趋势等特征缺乏信息论解释
3. **购买时序模式特征不足**：购买间隔分布、季节性购买模式未被系统编码
4. **特征冗余分析缺失**：RFM特征之间的互信息和冗余度未量化
5. **统计检验薄弱**：多数研究仅报告单次结果，缺乏多种子实验
